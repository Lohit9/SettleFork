Why the Graph View Replaces Investigation Agents

Current: AI writes understanding docs before mapping (~$2/table)

  • Investigation agent reads schema docs, writes field-by-field context
  • Human reads the doc to understand table relationships
  • Expensive, slow, and the output is a text wall nobody wants to read

Proposed: Graph shows structure instantly ($0)

  • FK relationships rendered as directed edges — see dependencies at a glance
  • Topological load order computed automatically — no AI needed
  • Click any table → jump to its field mappings
  • Color-coded readiness — green/amber/red per table
  • Cycle detection warns about circular deps before migration starts
  • Cascade highlighting — hover a table, see everything downstream
  • The human gets the "understanding" that the investigation agent was trying to produce, but visually and instantly

Edge Cases the Graph + Validation Catch

Edge CaseHow It ManifestsHow We Catch It
Circular FK Table A refs B, B refs A — can't load either first Kahn's topo-sort detects cycle, flags in graph as red nodes, suggests staged load + backfill
Orphan Records Orders ref customer_id=999, but customer 999 doesn't exist in source FK graph walk + validation query: count child rows with no parent match
Diamond Dependency BOM_Lines → BOM → Item_Master AND BOM_Lines → Item_Master (two paths) Topo-sort resolves longest path — Item_Master loads first regardless
Self-Reference employees.manager_id → employees.id (tree structure) Cycle detector catches single-node loop, suggests NULL FK + backfill
Disconnected Tables Lookup tables with no FK edges — might indicate missing annotations Graph renders them as isolated nodes, visually obvious
Hub Table Item_Master referenced by 5+ tables — change cascades everywhere Graph shows fan-in degree, hover highlights all dependents
Type Mismatch Source VARCHAR "2024-01-15" → target DATE, but some rows have "N/A" Deterministic type check + sample scan catches non-castable values
Silent Truncation Source VARCHAR(255) → target VARCHAR(40), data gets silently cut Max-length scan on source data vs target field width
